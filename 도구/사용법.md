# 단원 변환 도구

한 단원을 검토·변환할 때 쓴 스크립트 모음이다. (스크립트 안의 작업 폴더 경로는 그때그때 맞춰 바꾼다.)

1. `outline.py 섹션.xml header.xml` — 문항·해설·그림·표를 한 줄씩 펼쳐 읽기 (검토용)
2. `fix_uN.py 원본섹션 출력섹션` — 단원별 오타·오류 고치기, 단답형 바꾸기, bold 지우기, 괄호 정리, 빠른 정답 지우기
   (공통 함수: `common_fix.py`, `hwpedit.py`, 수식 폭 추정: `eqwidth.py`)
3. `figs.py 그림폴더` — 문제 속 그림 그리기 (`.claude/skills/math-figure-rules/mathfig.py` 약속 그대로)
   - KaTeX는 `npm pack katex@0.16.9`로 받아 `KATEX_DIR`, Chromium은 `CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome`
4. `insert_figs.py uN 섹션 출력 그림폴더 중앙정렬paraPr header.xml` — 옛 그림을 빼고 새 그림을 문제 아래 가운데에
5. `convert.py 원본폴더 섹션 그림json 양식폴더 출력.hwpx 단원번호 단원이름` — 양식(header·바탕쪽·용지)으로 옮겨 묶기
   - 글자·문단 모양은 같은 것이 양식에 있으면 그것을, 없으면 양식 header에 덧붙인다
   - 본문 글꼴 나눔명조 → 하는체 Regular, 개념 소제목 색 → #315F97
6. `validate.py 출력.hwpx 섹션` — 참조 id·그림·글 내용 검사
7. `make_log.py` — 수정기록.md에 붙일 표 만들기
