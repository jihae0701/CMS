# 클라우드 세션에서 그림 도구 돌리기
- CDN(jsdelivr)이 막혀 있으므로 KaTeX는 npm에서 받는다: `npm pack katex@0.16.9 && tar xzf katex-0.16.9.tgz` → `KATEX_DIR=<경로>/package/dist`
- `pip install playwright`, `CHROME=/opt/pw-browsers/chromium-1194/chrome-linux/chrome` (playwright install 하지 않음)
- 그림 넣기: BinData/imageN.png + content.hpf manifest에 `<opf:item id="imageN" href="BinData/imageN.png" media-type="image/png" isEmbeded="1"/>`
  + 본문에 `<hp:pic>`(hc:img binaryItemIDRef="imageN"), 폭은 PNG 픽셀(3배 해상도 기준 CSS px) × 6.4 HWPUNIT
