# 수학 문제 그림 약속

사용자가 문제집을 만들며 하나씩 정한 약속이다. 새 그림을 그릴 때는 이 약속을 모두 지키고,
문제집을 검토할 때는 아래 "검토 체크리스트"로 어긋난 그림을 찾아 알린다.
그리는 코드는 같은 폴더의 `mathfig.py`에 값까지 고정되어 있으므로, 그릴 때는 이것을 그대로 쓴다
(값을 바꾸지 않는다). 기준 그림은 `axes_example.png`(사용자가 고른 예시, 786픽셀 폭)와
길이 표시 기준 `example_length.png`이다.

## 1. 좌표축과 화살표
- 화살표 머리는 뒤가 오목하고 긴 모양: SVG `viewBox 0 0 13 10`, `M13,5 L0.5,0.3 L2.5,5 L0.5,9.7 z`
  (기준 그림의 x축 화살표: 길이 24, 반폭 9, 오목 3픽셀).
- **y**는 y축 화살표의 **왼쪽**에 쓰고, 글자 **윗끝을 화살표 끝 높이**에 맞춘다
  (글자 오른쪽 끝은 축보다 17픽셀 왼쪽, 기준 그림 786픽셀 폭 기준).
- **x**는 x축 **아래**에 쓰고, 글자 **오른쪽 끝이 화살표 끝 바로 왼쪽**(2픽셀)에 오게 한다(윗끝은 축 아래 22픽셀).
- 원점은 로만체 O로, 축의 왼쪽 아래에 쓴다. 점 이름은 모두 로만체(`\mathrm{A}`).
- 곡선이 y축 위쪽 왼편을 지나면 y 글자와 겹치지 않도록 **y축을 곡선 끝보다 길게** 그린다.
- 그래프와 x축의 위치 관계만 보여 주는 그림(판별식 D>0, D=0, D<0 등)은 x축만 그린다. 원본에 y축이 없는 그림도 x축만(`F.xaxis`).
- 가로축 변수가 x가 아니면 그 글자로 쓴다(예: f(t) 그래프는 `F.axes("t")`).

## 2. 선과 글자
- 굵기: 곡선·도형 테두리 3.2, 직선·선분 2.0, 좌표축 2.0, 점선 1.5(`5,4`), 직각 표시 1.6.
- 그림 안 글씨는 **모두 같은 크기(22px)**. 예외는 정육면체 면을 채우는 식 하나뿐.
- 함수식 속 분수는 `\dfrac`로 써서 숫자가 작아지지 않게 한다(예: y=−½x²+4x).
- 글자(점 이름·숫자·함수식)와 선·곡선 사이는 **8픽셀 이상** 띄운다(사용자: "선과 숫자가 겹치려 함").
  x절편 숫자처럼 곡선이 지나가는 자리 옆의 글자가 특히 붙기 쉽다. 원본 그림에서 겹쳐 있던 것도 옮긴다.
  `fit_shoot`가 그릴 때마다 글자 모양과 선의 간격을 재어, 붙은 글자를 가장 가까운 빈자리(22픽셀 안, 다른 글자와
  겹치지 않고 그림 밖으로 나가지 않는 곳)로 옮기고 옮긴 양을 `label_nudge.json`에 적는다.
  축 글자 x, y와 원점 O는 약속된 자리라 옮기지 않는다. 옮길 자리가 없거나 글자가 그림 밖으로 나가면 경고를 낸다.
- 점선은 보조선(점에서 축까지), 정의역 밖으로 이어 그린 곡선, 비교용으로 함께 그린 곡선에 쓴다. 실제 그래프는 실선(예: x≤1만 정의된 함수는 x≤1 실선, 나머지 점선).
- 원본의 빨강·파랑·초록 선은 **검은 선**으로 그린다. 구분은 곡선 끝의 이름표(y=f(x) 등)와 실선/점선으로 한다.
- 이름표를 둘 자리가 마땅치 않으면 짧은 지시선(`F.leader`, 굵기 1.2)으로 가리킨다(예: 겹친 꼭짓점의 3a, 모눈 위의 y=g(x)).
- 선 굵기는 그림마다 같게 한다(위 값). 실물을 나타내는 선(빛줄기, 기둥의 높이 표시 등)은 점선이 아니라 실선으로 그린다
  (점선 호는 길이 표시용; 사용자 요청).

## 3. 색칠
- 회색 대신 연한 색: 연분홍 `#ffd9e6`, 연두 `#dcf3d2`, 하늘 `#d6ecfb`, 연보라 `#e8defa`, 연노랑 `#fff3bf`.
- 한 문제에서 색칠한 부분이 2개 이상이면 원만할 때는 **한 색**으로 칠하고, 색을 달리해 구분하는 편이 나을 때
  (예: 두 넓이의 차 S₁−S₂)만 **비슷한 색끼리**(예: 하늘+연두) 쓴다.
- 정육면체 세 면은 연한 하늘색 한 색에 명도만 다르게: 위 `#ebf6fd`, 왼쪽 `#d6ecfb`, 오른쪽 `#c1e1f7`.
  면 안의 식은 면에 꽉 차게 크게(세 면 같은 크기, 한 변 길이의 0.17배 글씨).
- 그림자처럼 원래 회색인 것은 회색 그대로 둔다.

## 3-1. 벤 다이어그램·대응 그림·모눈
- 벤 다이어그램: 전체집합은 모서리가 둥근 직사각형, 집합은 원(타원). 집합 이름(U, A, B, P, …)은 **이탤릭**으로,
  **곡선(테두리)을 끊은 자리에** 쓴다(U는 위 변 왼쪽). `venn_universe`, `venn_set`(끊는 반쪽 길이 15px, 이 이름은 간격 검사에서 옮기지 않음).
  사용자가 특정 그림의 이름을 키우라고 하면 글씨와 끊는 길이를 같은 배율로 키운다(예: 1.6배 → 34px, 끊는 길이 24px).
- 대응(화살표) 그림: 두 타원(굵기 2.0), 원소 글자는 타원 가운데에 세로로, 화살표는 가는 선(1.5)과 작은 화살촉, 위에 X —f→ Y.
  `mapping(xs, ys, {x: y}, "X", "Y", "f")`. 문서 폭은 약 6000~7000(긴 변 약속의 예외; 그림 검사 경고는 무시).
- 모눈: 정수 격자를 연한 점선(`GRID`, 굵기 1.2)으로. 눈금 숫자는 축 바깥에. `F.grid(xs, ys)`.
- 여러 그래프를 한 장에: 칸마다 같은 크기로 그려 가로로 나란히(간격 30~40px). 두 칸이면 문서 폭 약 17000~20000,
  (1)~(8)처럼 많으면 칸 폭 약 5600으로 두 개씩 여러 줄. 칸 왼쪽 위에 (1), (2) 번호.

## 4. 도형 표시
- 선분의 길이는 선분 옆에 **휜 점선 호**를 긋고, **점선의 가운데를 끊어 그 끊은 자리에 길이를 쓴다**(`dim_arc`, 기본값).
  호 바깥에 글자를 따로 쓰지 않는다. 기준 그림: `example_length.png`(세로·가로 길이 12), `example_rect.png`.
  - 끊는 길이는 글자 크기에 맞춘다: 호가 가로로 지나면 글자 폭 + 여유, 세로로 지나면 글자 높이 + 여유.
  - 호는 넉넉히 휘게 한다: 가운데가 선분에서 **선분 길이의 0.2배 이상** 떨어지게(`dim_arc`가 자동으로 맞춤).
    길이 글자가 점 이름(Q 등)이나 선과 붙으면 더 휘게 한다. 호와 글자가 그림 밖으로 나가지 않게 그 쪽 여백을 넉넉히 둔다.
  - 끊은 점선 끝과 글자 사이도 띄운다(가로 호: 글자 폭 + 양쪽 10px, 세로 호: 글자 높이 + 양쪽 14px).
  - 문자 길이(x 등)도 같은 방법으로 쓴다.
- 직각은 작은 꺾인 선으로 표시한다(`right_mark`).
- 점은 지름 7픽셀 정도의 검은 점(`dot`).

## 5. 크기와 문서에 넣기
- 화살표·x, y 글자가 모든 그림에서 같은 크기로 보이도록 **PNG 1픽셀 = 6.4 HWPUNIT**으로 통일한다.
  문서에 넣을 폭(HWPUNIT)을 정하면 `fit_shoot(파일, 함수, 폭)`이 그림 크기(ZOOM)만 맞추고
  글자·화살표는 픽셀 크기 그대로 둔다. PNG는 3배 해상도로 찍는다.
- **도형의 크기와 글씨의 비율을 그림마다 같게**: 그래프·도형 그림은 **긴 변(가로·세로 중 긴 쪽)을 약 10000 HWPUNIT**
  (8900~11000)로 맞춘다. 글씨는 픽셀 크기가 고정이므로, 그림이 크면 도형에 비해 글씨가 작아 보이고 작으면 커 보인다
  (사용자: "도형이 너무 크게 그려짐"). `fit_shoot(파일, 함수)`처럼 폭을 주지 않으면 자동으로 긴 변 10000에 맞춘다.
  예외: 여러 그래프를 가로로 늘어놓은 개념 그림(폭 21000), 면에 식을 크게 쓰는 정육면체.
- 그림은 문제 문장 **아래 가운데**에 놓는다. 그래서 문장은 '오른쪽 그림과 같이'가 아니라 **'그림과 같이'**로 쓴다
  (그림이 실제로 오른쪽에 있을 때만 '오른쪽 그림').

## 5-1. 한글 문서에 붙여 넣은 스캔 그림 다시 그리기
사용자가 완성본(hwpx)에 스캔 그림(BMP·JPEG)을 붙여 넣었으면 그림마다 이 약속대로 다시 그려 PNG로 바꿔 넣는다.
1. 문서의 그림을 꺼내 모아 보고(BinData/imageN), 로고·아이콘(보기 표시 등)은 그대로 두고 문제·해설 그림만 고른다.
2. 문제 문장·해설에서 값(꼭짓점, 지나는 점, 조건)을 읽어 원본과 같은 모양으로 그린다. 원본에 없는 축·글자를 지어내지 않는다.
   값이 문자(a, b)뿐인 그림은 조건을 지키는 **개형**으로 그리고, 어떤 값으로 그렸는지 기록한다(예: a=1/4).
3. `fit_shoot`가 돌려준 폭으로 `python hwpx_swapimg.py 입력.hwpx 출력.hwpx image3=그림.png@10000 …`.
   떠 있는 그림(글자처럼 취급 안 함)은 원래 폭과 비슷하게, 글자처럼 취급하는 그림은 약속 폭으로.
4. 해설에 그래프를 새로 넣을 때는 그림 앞에 "…의 그래프는 다음과 같다." 한 줄을 두고, 같은 문서의 해설 그림 문단을 본떠 넣는다.
5. 바꾼 뒤 문서를 다시 열어(미리보기) 그림이 들어간 자리·크기를 확인하고, 무엇을 어떤 값으로 그렸는지 기록한다.

## 6. 그림의 내용
- 그림은 **답이 드러나지 않도록 답과 다른 값으로 그린 개형**이다. 단, 접한다·지난다 같은 관계는 지킨다.
- 모의고사 문항은 원본 그림의 모양(굵은 곡선, 가는 직선, 점 이름, 빗금, 직각 표시)을 따라 다시 그리고,
  위 약속(축·글자·색)으로 맞춘다. 원래 그림이 이해를 돕던 문항은 그림을 빼지 않는다.
- 원본 그림이 잘렸거나 표시가 빠졌으면 다시 그린다.
- 그림을 설명하려고 문장이 길어졌다면(x절편 나열 등) 원본처럼 '그래프가 그림과 같다'로 줄인다.

## 7. 그리는 방법 (`mathfig.py`)
```python
from mathfig import Frame, fit_shoot, roots, dot, right_mark, dim_arc, SKY, GREEN

def fig():
    f = lambda t: 0.5 * (t + 2) * (t - 3)
    F = Frame((-3.6, 4.6), (-3.6, 2.6), 34, 34, (20, 12, 70, 12))  # x범위, y범위, 한 칸 px, 여백
    F.axes()                                                       # 약속된 축·화살표·x, y
    F.curve(f, roots(f, -6, 0.5, 2.3)[0], roots(f, 0.5, 7, 2.3)[0])  # 보이는 높이 2.3에서 곡선을 끊음
    F.pt((0, 0), "O", "rt", -4, 4)                                 # 기준점 위치: 가로 l/c/r + 세로 t/c/b
    F.lab((-2, 0), "-2", "rt", -3, 4); F.lab((3, 0), "3", "lt", 3, 4)
    return F.render()

w = fit_shoot("graph.png", fig)   # 긴 변 10000 HWPUNIT에 맞추고 글자 간격 검사·옮김. 돌려주는 값 = 문서에 넣을 폭
```
- 색칠은 `F.poly(점들, SKY)`(테두리 없이 맨 아래 층), 선분 `F.seg`, 점선 `F.dashed`, 꺾은선 `F.polyline(점들[, DASH])`,
  점선 곡선 `F.curve(f, a, b, DASH)`, 모눈 `F.grid`, 지시선 `F.leader`, 벤 다이어그램 `venn_universe`·`venn_set`, 대응 그림 `mapping`.
- 필요: `pip install playwright` 후 Chromium. KaTeX는 `KATEX_DIR`(katex/dist)가 있으면 그것을, 없으면 CDN을 쓴다.
  Chromium 경로가 따로 있으면 `CHROME` 환경 변수로 준다.
- `python mathfig.py`를 실행하면 시험 그림 네 장(example_graph.png, example_rect.png, example_venn.png, example_map.png)이 나온다.
- 문서의 그림 바꾸기: `hwpx_swapimg.py`(위 5-1).
- 길이 표시: `dim_arc(F, B, C, "12", 1)`처럼 쓴다(점, 점, 글자, 휘는 쪽 +1/-1[, 최소 휘는 정도 px]). 점선 가운데를 끊고 글자를 넣고,
  선분 길이의 0.2배 이상 휜다.
- 그림 검사만 따로: `check_and_nudge(이름, html, w, h)`가 붙은 글자를 옮기고 남은 문제를 돌려준다(`fit_shoot`가 부른다).
- 문서(hwpx)의 그림은 PNG 크기 × 6.4로 폭·높이를 넣는다(그림을 다시 그리면 문서의 그림 크기도 함께 바꾼다).

## 검토 체크리스트 (문제집 오타·오류 검토용)
그림마다 아래를 확인하고, 어긋나면 "문항 번호 / 무엇이 / 약속은 무엇"으로 적는다.
1. 화살표가 뒤가 오목한 긴 모양인가, y가 화살표 왼쪽·x가 축 아래 화살표 끝 왼쪽인가
2. 곡선이 y 글자와 겹치지 않는가(겹치면 y축을 더 길게)
3. 그림 안 글씨 크기가 모두 같은가, 분수가 작아지지 않았는가
4. 색칠이 회색이 아닌 연한 색인가, 여러 부분이면 한 색 또는 비슷한 색끼리인가
5. 길이 표시가 휜 점선 호(선분 길이의 0.2배 이상 휨)이고 **점선 가운데를 끊은 자리**에 길이가 있는가(호 바깥에 따로 쓰지 않았는가), 직각 표시가 있는가, 길이 표시가 아닌 실물 선이 점선으로 그려지지 않았는가
6. 같은 책의 그림끼리 화살표·글자 크기·선 굵기가 같아 보이는가(1픽셀=6.4 HWPUNIT), 도형 크기와 글씨의 비율이 같은가(긴 변 약 10000 HWPUNIT; 유난히 크거나 작은 그림이 없는가)
7. 그림이 답을 그대로 보여 주지 않는가(개형), 문제의 조건(접함, 지남, 교점, x절편)과 맞는가
8. 문장이 '그림과 같이'인데 그림이 빠지지 않았는가, 그림 속 이름(점, 함수식)이 문제 문장과 같은가
9. 글자와 선·곡선 사이가 8픽셀 이상인가(특히 x절편 숫자, 교점 이름), 글자·호가 그림 밖으로 잘리지 않았는가
10. 벤 다이어그램 이름이 곡선을 끊은 자리에 이탤릭으로 있는가, 대응 그림의 화살표가 원소를 정확히 잇는가
11. 붙여 넣은 스캔 그림(BMP·흐린 그림·색 선)이 남아 있지 않은가, 정의역 밖 부분이 점선인가
