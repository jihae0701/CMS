# 수학 문제 그림 약속

사용자가 문제집을 만들며 하나씩 정한 약속이다. 새 그림을 그릴 때는 이 약속을 모두 지키고,
문제집을 검토할 때는 아래 "검토 체크리스트"로 어긋난 그림을 찾아 알린다.
그리는 코드는 같은 폴더의 `mathfig.py`에 값까지 고정되어 있으므로, 그릴 때는 이것을 그대로 쓴다
(값을 바꾸지 않는다). 기준 그림은 `axes_example.png`(사용자가 고른 예시, 786픽셀 폭)와
길이 표시 기준 `example_length.png`이다.

## 1. 좌표축과 화살표
- 화살표 머리는 뒤가 오목하고 긴 모양: SVG `viewBox 0 0 13 10`, `M13,5 L0.5,0.3 L2.5,5 L0.5,9.7 z`
  (기준 그림의 x축 화살표: 길이 24, 반폭 9, 오목 3픽셀).
- **y**는 y축 화살표의 **왼쪽**에 쓰고, 글자 **윗끝을 화살표 끝 높이**에 맞춘다
  (글자 오른쪽 끝은 축보다 17픽셀 왼쪽, 기준 그림 786픽셀 폭 기준).
- **x**는 x축 **아래**에 쓰고, 글자 **오른쪽 끝이 화살표 끝 바로 왼쪽**(2픽셀)에 오게 한다(윗끝은 축 아래 22픽셀).
- 원점은 로만체 O로, 축의 왼쪽 아래에 쓴다. 점 이름은 모두 로만체(`\mathrm{A}`).
- 곡선이 y축 위쪽 왼편을 지나면 y 글자와 겹치지 않도록 **y축을 곡선 끝보다 길게** 그린다.
- 그래프와 x축의 위치 관계만 보여 주는 그림(판별식 D>0, D=0, D<0 등)은 x축만 그린다.

## 2. 선과 글자
- 굵기: 곡선·도형 테두리 3.2, 직선·선분 2.0, 좌표축 2.0, 점선 1.5(`5,4`), 직각 표시 1.6.
- 그림 안 글씨는 **모두 같은 크기(22px)**. 예외는 정육면체 면을 채우는 식 하나뿐.
- 함수식 속 분수는 `\dfrac`로 써서 숫자가 작아지지 않게 한다(예: y=−½x²+4x).
- 글자가 선이나 곡선에 붙거나 겹치면 자리를 옮긴다(원본 그림에서 겹쳐 있던 것도 옮긴다).

## 3. 색칠
- 회색 대신 연한 색: 연분홍 `#ffd9e6`, 연두 `#dcf3d2`, 하늘 `#d6ecfb`, 연보라 `#e8defa`, 연노랑 `#fff3bf`.
- 한 문제에서 색칠한 부분이 2개 이상이면 원만할 때는 **한 색**으로 칠하고, 색을 달리해 구분하는 편이 나을 때
  (예: 두 넓이의 차 S₁−S₂)만 **비슷한 색끼리**(예: 하늘+연두) 쓴다.
- 정육면체 세 면은 연한 하늘색 한 색에 명도만 다르게: 위 `#ebf6fd`, 왼쪽 `#d6ecfb`, 오른쪽 `#c1e1f7`.
  면 안의 식은 면에 꽉 차게 크게(세 면 같은 크기, 한 변 길이의 0.17배 글씨).
- 그림자처럼 원래 회색인 것은 회색 그대로 둔다.

## 4. 도형 표시
- 선분의 길이는 선분 옆에 **휜 점선 호**를 긋고, **점선의 가운데를 끊어 그 끊은 자리에 길이를 쓴다**(`dim_arc`, 기본값).
  호 바깥에 글자를 따로 쓰지 않는다. 기준 그림: `example_length.png`(세로·가로 길이 12), `example_rect.png`.
  - 끊는 길이는 글자 크기에 맞춘다: 호가 가로로 지나면 글자 폭 + 여유, 세로로 지나면 글자 높이 + 여유.
  - 호는 넉넉히 휘게 한다(가운데가 선분에서 약 16~46픽셀). 길이 글자가 점 이름(Q 등)이나 선과 붙으면 더 휘게 한다.
    아래쪽 변의 호도 꼭짓점 이름(B, C)과 겹치지 않을 만큼 아래로 휘게 한다(예시: 아래 호 30, 왼쪽 호 46).
  - 문자 길이(x 등)도 같은 방법으로 쓴다.
- 직각은 작은 꺾인 선으로 표시한다(`right_mark`).
- 점은 지름 7픽셀 정도의 검은 점(`dot`).

## 5. 크기와 문서에 넣기
- 화살표·x, y 글자가 모든 그림에서 같은 크기로 보이도록 **PNG 1픽셀 = 6.4 HWPUNIT**으로 통일한다.
  문서에 넣을 폭(HWPUNIT)을 정하면 `fit_shoot(파일, 함수, 폭)`이 그림 크기(ZOOM)만 맞추고
  글자·화살표는 픽셀 크기 그대로 둔다. PNG는 3배 해상도로 찍는다.
- 자주 쓴 폭: 작은 그래프·도형 9000, 보통 11000, 넓은 그림 12500, 개념 설명 가로 그림 21000.
- 그림은 문제 문장 **아래 가운데**에 놓는다. 그래서 문장은 '오른쪽 그림과 같이'가 아니라 **'그림과 같이'**로 쓴다
  (그림이 실제로 오른쪽에 있을 때만 '오른쪽 그림').

## 6. 그림의 내용
- 그림은 **답이 드러나지 않도록 답과 다른 값으로 그린 개형**이다. 단, 접한다·지난다 같은 관계는 지킨다.
- 모의고사 문항은 원본 그림의 모양(굵은 곡선, 가는 직선, 점 이름, 빗금, 직각 표시)을 따라 다시 그리고,
  위 약속(축·글자·색)으로 맞춘다. 원래 그림이 이해를 돕던 문항은 그림을 빼지 않는다.
- 원본 그림이 잘렸거나 표시가 빠졌으면 다시 그린다.
- 그림을 설명하려고 문장이 길어졌다면(x절편 나열 등) 원본처럼 '그래프가 그림과 같다'로 줄인다.

## 7. 그리는 방법 (`mathfig.py`)
```python
from mathfig import Frame, fit_shoot, roots, dot, right_mark, dim_arc, SKY, GREEN

def fig():
    f = lambda t: 0.5 * (t + 2) * (t - 3)
    F = Frame((-3.6, 4.6), (-3.6, 2.6), 34, 34, (20, 12, 70, 12))  # x범위, y범위, 한 칸 px, 여백
    F.axes()                                                       # 약속된 축·화살표·x, y
    F.curve(f, roots(f, -6, 0.5, 2.3)[0], roots(f, 0.5, 7, 2.3)[0])  # 보이는 높이 2.3에서 곡선을 끊음
    F.pt((0, 0), "O", "rt", -4, 4)                                 # 기준점 위치: 가로 l/c/r + 세로 t/c/b
    F.lab((-2, 0), "-2", "rt", -3, 4); F.lab((3, 0), "3", "lt", 3, 4)
    return F.render()

fit_shoot("graph.png", fig, 9000, ".")   # 문서 폭 9000 HWPUNIT
```
- 색칠은 `F.poly(점들, SKY)`(테두리 없이 맨 아래 층), 선분 `F.seg`, 점선 `F.dashed`.
- 필요: `pip install playwright` 후 Chromium. KaTeX는 `KATEX_DIR`(katex/dist)가 있으면 그것을, 없으면 CDN을 쓴다.
  Chromium 경로가 따로 있으면 `CHROME` 환경 변수로 준다.
- `python mathfig.py`를 실행하면 시험 그림 두 장(example_graph.png, example_rect.png)이 나온다.
- 길이 표시: `dim_arc(F, B, C, "12", 1, 30)`처럼 쓴다(점, 점, 글자, 휘는 쪽 +1/-1, 휘는 정도 px). 점선 가운데를 끊고 글자를 넣는 것이 기본이다.

## 검토 체크리스트 (문제집 오타·오류 검토용)
그림마다 아래를 확인하고, 어긋나면 "문항 번호 / 무엇이 / 약속은 무엇"으로 적는다.
1. 화살표가 뒤가 오목한 긴 모양인가, y가 화살표 왼쪽·x가 축 아래 화살표 끝 왼쪽인가
2. 곡선이 y 글자와 겹치지 않는가(겹치면 y축을 더 길게)
3. 그림 안 글씨 크기가 모두 같은가, 분수가 작아지지 않았는가
4. 색칠이 회색이 아닌 연한 색인가, 여러 부분이면 한 색 또는 비슷한 색끼리인가
5. 길이 표시가 휜 점선 호이고 **점선 가운데를 끊은 자리**에 길이가 있는가(호 바깥에 따로 쓰지 않았는가), 글자가 점 이름·선과 붙지 않는가, 직각 표시가 있는가
6. 같은 책의 그림끼리 화살표·글자 크기가 같아 보이는가(1픽셀=6.4 HWPUNIT)
7. 그림이 답을 그대로 보여 주지 않는가(개형), 문제의 조건(접함, 지남, 교점, x절편)과 맞는가
8. 문장이 '그림과 같이'인데 그림이 빠지지 않았는가, 그림 속 이름(점, 함수식)이 문제 문장과 같은가
9. 글자가 선·곡선에 붙거나 겹치지 않는가, 그림이 잘리지 않았는가
