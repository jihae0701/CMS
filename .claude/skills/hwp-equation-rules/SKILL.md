# 한글 수식 쓰는 약속

사용자가 공통수학 문제집(기본서·유형서)을 만들며 정한 약속이다. 수식은 한글 수식 편집기 스크립트
(hwpx의 `<hp:script>`)로 쓴다. 새 수식을 쓸 때는 이 약속을 지키고, 문서를 검토할 때는 `eqcheck.py`와
아래 "검토 체크리스트"로 어긋난 곳을 찾아 "문항 번호 / 무엇이 / 약속은 무엇"으로 알린다.
사용자가 완성본에서 직접 고친 표기가 있으면 그것이 새 기준이다(이 문서를 고친다).

## 1. 무엇을 수식으로 쓰나
- **문제에 속한 수와 영문자만 수식으로** 쓴다(숫자 하나, 문자 하나도 수식). 한글은 수식 밖 글자로 쓴다.
- 기본서의 개념 설명처럼 원본이 있는 글은 원본 그대로 두고 수식으로 바꾸지 않는다.
- 긴 식은 앞뒤를 줄바꿈해 한 줄에 따로 둔다(예: '모든 실수 $x$에 대하여 ⏎ [식] ⏎ 를 만족시킬 때').
- 해설(2단의 한 단, 폭 약 29,600 HWPUNIT)에서 단 폭을 넘는 식은 괄호 밖의 '='(없으면 '+', '−')에서 나눠 다음 줄로.

## 2. 기본 표기
| 무엇 | 쓰는 법 | 예 |
|---|---|---|
| 분수 | `{a} over {b}` (중괄호와 over 사이 빈칸) | `{3} over {4}`, `- {1} over {2} x` |
| 큰 괄호 | `LEFT ( … RIGHT )`, `LEFT { … RIGHT }` (분수·첨자가 든 괄호) | `LEFT ( x+ {1} over {2} RIGHT ) ^{2}` |
| 쉼표 | 좌표·목록의 쉼표 뒤는 `~` | `(1,~2)`, `LEFT { 1,~2,~3 RIGHT }`, `1,~2,~CDOTS,~10` |
| 점·선분 이름 | 로만체 `rm` + 빈칸 | `rm A(1,~2)`, `overline {rm AB}`, `angle {rm ABC} =90^{circ}` |
| 선분의 제곱 | 윗줄 밖에 제곱 | `{overline {rm AB}}^{2}` |
| 비 | 쌍점 앞뒤 `` ` `` | `m`:`n`, `2`:`3` |
| 부등호 | `leq`, `geq`, `<`, `>`, `!=`(≠) | `1<x leq 6` |
| 곱·점 | `times`(또는 `TIMES`), `CDOTS`/`cdots` | `8 times 16=128` |
| 기호 | `therefore`(∴), `PLUSMINUS`(±), `emptyset`, `in`, `notin`, `circ`(합성), `pi`, `alpha`, `beta` | `t=-2 PLUSMINUS 2 sqrt {2}` |
| 제곱근 | `sqrt {…}` | `sqrt {x^{2} +1}` |
| 거듭제곱·첨자 | `^{…}`, `_{…}` (중괄호) | `x^{2}`, `a_{n}`, `f^{-1} (x)` |
| 극한(lim) | 아래첨자의 화살표 앞뒤에 `` ` ``를 하나씩(미적분 시리즈 약속) | `lim _{x `-> `inf} f(x)`, `lim _{x `-> `2} {x^{2} -4} over {x-2}`, `lim _{x `-> `-inf}` |
| 행렬 | `pmatrix{a&~b#c&~d}` — 문자 바로 뒤면 빈칸(`A pmatrix…`) | `A= pmatrix{1&~2#3&~4}` |
| 기울임 | 상수·변수를 기울여야 할 때 `it` | `x_{1}`, `A( it a,~b)` |

## 3. 음수와 '<-' 함정
- 관계 기호(=, <, >, leq, geq) 바로 뒤의 음수는 `it-`로 쓴다: `x= it-2`, `x< it-1`, `b= it-5`, `it-LEFT|`.
  (빼기 기호가 이항 연산처럼 벌어지지 않게. 완성본에는 `=-1`도 남아 있으니 새로 쓸 때 지키고, 검토에서는 '권장'으로만 알린다.)
- **'<-'는 한글 수식에서 왼쪽 화살표(←)** 명령이다. `x<-1`은 'x←1'로 보인다 → `x< it-1`. (`eqfix.py`가 고친다)

## 4. 붙여 쓰면 잘못 보이는 것
- 수·문자 바로 뒤의 명령은 띄어 쓴다. 붙이면 한 낱말로 읽힌다: `3 overline {rm AB}`(×`3overline`), `2 alpha beta`(×`2alpha beta`, ×`alphabeta`),
  `A pmatrix{…}`, `k pi`.
- 계승 뒤의 등호는 띄운다: **`5! =120`**(×`5!=120` → 5≠120으로 보임). 같지 않음은 `a != 0`.
- `rm` 뒤는 빈칸: `rm A`, `rm {AB}`(×`rmA`).
- 중괄호 짝을 맞춘다(남거나 빠진 `{` `}`는 한글에서 엉뚱하게 보이거나 뒤 수식을 망친다). cases의 닫는 `}`가 자주 빠진다.
- 빈 수식 개체를 남기지 않는다.

## 5. 집합
- 여집합은 **`A^{∁}`**(U+2201 ∁). `^{C}` 쓰지 않음.
- 조건제시법의 세로줄은 **`left|`**: `LEFT { x left| x^{2} =1 RIGHT }`. `` `vert` `` 쓰지 않음.
- **조건 속 한글은 수식 밖 글자로** 나눈다: 수식 `U=LEFT { x left| x` + 글자 '는 ' + 수식 `10` + 글자 '이하의 자연수' + 수식 `it right`.
  조건이 수식으로 끝나면 마지막 수식에 `RIGHT }`: 수식 `X=LEFT { x left| x in A` + 글자 '이고 ' + 수식 `x notin B RIGHT }`.
  (cases·pile처럼 여러 줄인 수식, 중괄호 안의 한글은 나누지 않는다.)
- 합의 줄임표: `s_{1} + it CDOTS it +s_{n}`. 목록 `1,~2,~CDOTS,~10`은 그대로.
- 집합 기호는 소문자: `subset`, `nsubset`, `sim`, `cap`, `cup`(대문자 SUBSET·NSUBSET·SIM·SMALLINTER·CUP 쓰지 않음).
- 큰 괄호 높이를 맞출 때 `pile{it#it}`를 쓴 곳은 그대로 둔다.

## 6. 명제·함수
- **명제의 화살표 앞뒤에 빈칸**: `p`` rarrow ``q`, `sim p`` rarrow ``sim q`, 필요충분 `p ``RARROW ``q`.
- 조건 표기는 쌍점 뒤 빈칸 없이: 글 '조건 $p$:$x^{2} …$'.
- 함수 표기: `f`:`X`` rarrow ``Y` (함수 단원의 이 화살표에는 명제 규칙을 따로 적용하지 않는다).
- 합성·역함수: `(f circ g)(x)`, `f^{-1} (x)`, `f^{n+1} =f circ f^{n}`.

## 7. 구간별 식(cases)
- `{cases{x+2 & (x<1) # ax^{2} +bx+5 & (x geq 1)}}` — 조건은 괄호 안, 줄은 `#`.
- 줄 맞춤이 필요하면 `_{it}`(빈 첨자)로 맞춘다: `cases{-x+4 ~_{it}& (x< it-2) _{it}# f(x) _{it}& (-2 leq x leq 1)}`.
- 조건 `|x|<2`는 `( LEFT | x RIGHT | <2)`.

## 8. 수식과 글자 사이
- 수식 바로 뒤의 **'이하·이상·미만·초과·또는·그리고' 앞은 한 칸 띄운다**: '$10$ 이하의 자연수', '$x<2$ 또는 $x>5$'.
- 조사·단위는 붙인다: '$x$는', '$3$개', '$2$의', '$k$로'.
- 수식 안에 `~또는~`처럼 한글을 넣지 않는다(수식을 나눠 글자로).

## 9. 수식 크기(hwpx를 직접 만들 때)
- 수식 개체의 폭·높이·기준선은 KaTeX로 재어 넣는다(`eqmeasure.py` → `eqstyle.sizes`): 폭 = 68.8×px+61, 높이 1125(보통)·1313(위 첨자)·
  1350(아래 첨자)·1538(제곱근)·분수 등 큰 식은 57.14×px+303, 기준선 비율 50~90. 글자 크기는 문단 글자 크기와 같게(10pt면 baseUnit 1000).
- 잰 값은 `eqcache.json`에 모인다. `KATEX_DIR`(katex/dist) 없이 재면 근사값이 저장되므로 반드시 지정한다.

## 10. 도구
- `python eqcheck.py 파일.hwpx [--all]` — 위 약속에 어긋난 수식을 종류별로 보여 준다(고치지 않음). 사람이 보고 고친다.
- `python eqstyle.py 파일.hwpx` — 5장(여집합·left|·조건 속 한글 나누기·줄임표)과 8장(수식 뒤 빈칸)을 그 자리에서 입힌다.
  `--prop`을 주면 6장 명제 화살표 빈칸과 소문자 집합 기호까지(함수 단원 문서에는 쓰지 않는다). 수식을 나누면 새 수식 크기를 잰다.
- `python eqfix.py 파일.hwpx` — '<-' → '< it-'.
- `hwp2latex.py` — 한글 수식 스크립트를 LaTeX로 바꾸는 근사 변환(크기 재기·미리보기용).
- 필요: Python 3, `pip install playwright`(Chromium; 경로가 따로 있으면 `CHROME`), `npm install katex` 후 `KATEX_DIR`. `eqcheck.py`·`eqfix.py`는 표준 라이브러리만 쓴다.

## 검토 체크리스트
1. 문제에 속한 수·영문자가 모두 수식인가, 한글이 수식 안에 들어가 있지 않은가
2. 중괄호 짝이 맞는가(cases의 닫는 `}`), 빈 수식이 없는가
3. '<-'(←로 보임), '5!=120'(≠로 보임), 붙여 쓴 명령(`3overline`, `2alpha`, `rmA`, `Apmatrix`)이 없는가
4. 관계 기호 뒤 음수가 `it-`인가(권장)
5. 좌표·목록 쉼표 뒤 `~`, 점 이름 `rm`, 선분 `overline {rm AB}`, 제곱은 `{overline {rm AB}}^{2}`인가
6. 여집합 `^{∁}`, 조건제시법 `left|`, 조건 속 한글이 수식 밖인가, 줄임표 `+ it CDOTS it +`인가
7. 명제 화살표 앞뒤 `` `` ``, 집합 기호 소문자인가
8. cases 조건이 괄호 안이고 줄 맞춤이 되어 있는가
9. '이하·이상·미만·초과·또는·그리고' 앞이 띄어져 있고 조사는 붙어 있는가
10. 해설 단 폭을 넘는 긴 식이 없는가(넘으면 '='에서 나눔)
