# 내신고쟁이 공통수학2 (사용자 hwp, 2026-11-08)

사용자가 올린 hwp 5개(04 도형의 이동 ~ 08 유리함수와 무리함수)에서 `도구/hwp5text.py`로 본문 글과 수식 스크립트를 꺼낸 것.
세션 임시 폴더가 지워져도 다시 올릴 필요가 없도록 저장소에 둔다. 원본 hwp는 넣지 않는다.

- 글 순서: 문항 첫 줄 → `[정답]`과 풀이 → 문항 나머지(조건·보기 표) → 선지. 문항 번호는 파일에 없다.
- 각 파일은 소단원 01~0N이 두 번 나온다(앞: 개념 확인 문항, 뒤: 실전 문항).
- 06 명제 파일의 소단원 06이 절대부등식(8단원 재료).
