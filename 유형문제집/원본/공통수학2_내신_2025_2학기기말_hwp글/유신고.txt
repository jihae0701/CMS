[부등식 증명]
부등식의 좌변에서 우변을 뺀 차를  $D$ 라 하고,  $D  GEQ 0$ 임을 보인다.
$D = 2(a^{4} + b^{4}) - (a +b)(a^{3} + b^{3})$
먼저 우변을 전개하면
$(a +b)(a^{3} + b^{3}) = a^{4} + a b^{3} + b a^{3} + b^4$
$D$ 를 정리하면
$D = 2a^{4} + 2b^{4} - (a^{4} + b^{4} + a^{3} b + a b^{3})$
$D = a^{4} + b^{4} - a^{3} b - a b^3$
식을 인수분해하기 위해 항을 묶는다.
$D = a^{3} (a - b) - b^{3} (a - b)$
$D = (a - b) (a^{3} - b^{3})$
이때, 인수분해 공식  $a^{3} - b^{3} =  ( a -b )  ( a^{2} + ab + b^{2} ) $ 를 사용한다.
$D = (a - b) [(a - b)(a^{2} + ab + b^{2})]$
$D = (a - b)^{2} (a^{2} + ab + b^{2})$
$a, b$ 는 실수이므로  $ ( a - b ) ^2  GEQ 0$ 이다.
$a^{2} + ab + b^{2} =  LEFT(a + {b} over {2} RIGHT)^{2} + {3} over {4} b^2$
$a, b$ 는 실수이므로  $ LEFT ( a + {b} over {2} RIGHT ) ^2  GEQ 0$ 이고,  ${3} over {4} b^{2}  GEQ 0$ 이다. (∵ 실수의 제곱은 항상 0 이상이다.)
따라서  $a^{2} + ab + b^{2}  GEQ 0$ 이다.
결론적으로  $D$ 는 0 이상의 두 실수의 곱이므로  $D  GEQ 0$ 이다.
$2(a^{4} + b^{4}) - (a +b)(a^{3} + b^{3})  GEQ 0$
따라서  $2 ( a^{4} + b^{4} )   GEQ  ( a +b )  ( a^{3} + b^{3} ) $ 은 항상 성립한다.
[등호 성립 조건]
등호는  $D = 0$ 일 때 성립한다.
$(a - b)^{2} (a^{2} + ab + b^{2}) = 0$
곱이 0이 되려면  $ ( a - b ) ^2 = 0$ 이거나  $a^{2} + ab + b^{2} = 0$ 이어야 한다.
1.   $ ( a - b ) ^2 = 0$  이면  $a = b$ 이다.
2.   $a^{2} + ab + b^{2} = 0$  이면  $ LEFT ( a + {b} over {2} RIGHT ) ^2 + {3} over {4} b^{2} = 0$ 이므로  $b =0$ 이고  $a + {b} over {2} = 0$ 이다. 즉,  $a =0, b =0$ 이다.
$a =b$  조건은  $a =0, b =0$ 인 경우를 포함하는 더 일반적인 조건이다.
따라서 등호는  $a =b$ 일 때 성립한다.
