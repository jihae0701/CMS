# 대수 CLIMATH(C) 수정기록

작업 약속은 저장소 맨 위의 `미적분Ⅰ_작업약속.md`, `대수_작업계획.md` 참고. 미적분Ⅰ ⓒ와 같은 기준으로 다시 편집함.

## 모든 단원 공통
- 바탕쪽: 미적분Ⅰ ⓒ 바탕쪽을 쓰고 과목명 '미적분Ⅰ' → '대수', 짝수 쪽 CLIMATH 로고·ⓒ 표시, 쪽 번호 1부터
- 틀: STEP 1 개념 익히기 / STEP 2 유형별 학습하기 / STEP 3 단원 마무리 하기 제목, 굵은 글씨 정리, 단원 끝 정답 모음 지움, 정답 머리 "[정답]"(굵지 않게)
- 글꼴: 문제·해설 글꼴을 미적분Ⅰ ⓒ 1단원과 같게(문제 하는체 Regular, 수식 HancomEQN)
- 수식: hwp-equation-rules 약속대로 자동 정리(분수 묶음, 짝 없는 중괄호, 묶지 않은 첨자, 붙여 쓴 명령, 기호 글자 ÷·±·≠·≥·≤ → div·+-·neq·geq·leq, 근호 지수 자리 등) 뒤 문항마다 손으로 확인
- 문장: "~하여라/나타내어라" → "구하시오/나타내시오", 여러 답은 "모두 구하시오", 해설은 "-이다" 꼴
- 단답형: 어색하지 않은 객관식은 단답형으로(보기 ㄱㄴㄷ, 옳은/옳지 않은 것, 식·구간 고르기는 객관식 유지)
- 그림: 스캔 그림은 math-figure-rules 약속대로 모두 다시 그림(긴 변 약 10000 HWPUNIT, 1픽셀=6.4 HWPUNIT, 진한 칠은 연한 색). 보기·참고 표시 그림은 그대로. 그리는 스크립트는 `그림/`에
