# 공통수학 유형 문제집 제작 기준

학원 내부 수업용. 공통수학1 → 공통수학2 순서로 2권 제작.

## 파일 형식
- HWPX, 단원별 1파일 (`01_다항식의_연산과_항등식.hwpx` … `12_행렬.hwpx`)
- 틀은 `기본폼_공통수학1_01.hwpx`(학원 한글 폼)를 그대로 쓴다: 2단, 한 단에 한 문제, 유형 제목 상자, 단원 머리표, 머리말·쪽 번호, 끝의 「정답 및 풀이」
- 보기 박스, 조건 박스, 두 줄 식(구간별 식), (가) 꼬리표는 `서식샘플.hwpx` 형식을 따른다.
  - 보기 박스와 조건 박스는 모두 표 칸 안에 **선 없는 글상자**를 두고 그 안에 글을 쓴다(서식샘플의 두 상자 그대로). 글상자 안쪽 여백은 왼쪽·오른쪽 1.5mm, 아래 2mm.
  - 글상자는 내용에 맞춰 저절로 늘어나지 않으므로 높이를 줄 수로 계산해 넣는다(사용자 예시 44번 상자와 같은 높이가 나오도록 맞춤).
- 폼의 그림이 잘렸거나 표시가 빠진 경우 `도구/그림/draw.py`로 다시 그려 `도구/그림/imageNN.png`로 둔다. `gen.py`가 폼의 같은 그림 대신 넣는다(1단원 4번 정육면체, 17번 직각삼각형).
- 해설은 미주(문제 끝에 정답·해설)로 넣는다. 미주 번호가 곧 문제 번호다.
- 나중에 단원 파일을 한 권으로 합치므로 **문항 번호는 단원을 넘어 이어진다**(유형서 1단원 1~61, 2단원 62~122). 단원 파일의 `START`에 첫 번호를 적는다. 문제 번호는 문단 번호(번호 정의 2번)로 붙으므로, 한글의 '새 번호로 시작'처럼 번호 정의의 시작 번호를 `START`로 바꾼다(미주 번호도 같이 맞춤).
- 모의고사 문항은 번호 옆에 출처를 적는다. (예: 2025년 6월 고1 14번 [4점])

## 구성 (2스텝)
- **STEP 1**: 참고 교재(일품)의 1스텝(개념 & 핵심 기출)과 2스텝(고난도)을 같은 개념끼리 합친 유형별 문제
- **STEP 2**: 고난도 문제 (폼의 「고난도」 제목, 새 쪽에서 시작)
- 유형 제목은 일품의 개념 이름을 쓴다.
- 비율: STEP 1 약 75% / STEP 2 약 25% (1단원 기준 45 + 15)
- 너무 단순한 쉬운 문제는 유형마다 1개까지만

## 난이도 (학원 학생이 상위권)
- 단원 전체 기준으로 **상 30%**(2단원 나머지정리는 **35%**), **최상 3문제**
- STEP 1: 유형마다 끝에 상을 1~2문제씩 둔다.
- STEP 2(고난도): 상으로 채우고, 마지막 3문제를 최상으로 둔다.
- 문제·정답·해설 어디에도 난이도를 표시하지 않는다. (단원 파일의 `LEVEL`에만 기록)

## 분량
- 1단원: 61문항, 2단원: 61문항 (질문할 문제를 줄이려고 66·69문항에서 줄임)
- 숫자·풀이가 거의 같은 문항은 문항 수를 채우지 않더라도 뺀다.
- 3~12단원: 단원마다 70~90문항

## 문제 출처
| 출처 | 사용 기준 | 출처 표기 |
|---|---|---|
| 내신 기출 | 기본 | 안 함 |
| 모의고사(학력평가) | 4점 문항만 | 함 (예: 2025년 9월 고1 학력평가 17번) |
| 올림포스 고난도 (EBS) | 단원마다 20% | 안 함 |
| 올림포스 유형편 (EBS) | 내신·모의고사로 부족한 유형만 채움 | 안 함 |

- 단원 구성 참고 교재: 일품 공통수학1 591제 (좋은책신사고). 문제는 가져오지 않고 개념 순서만 참고한다.

## 기본서와의 관계
- **목표: 기본서를 충분히 공부한 학생이 유형서에서 질문할 문제가 단원마다 10개 이하.** (한두 문제는 넘어도 됨)
  - 아직 배우지 않은 단원의 방법(예: 1·2단원에서 인수분해의 공통부분 묶기, x⁴+x²+1의 인수분해)이 필요한 문제는 넣지 않는다. 그 단원으로 옮긴다.
  - 기본서에 없는 방법을 쓰는 어려운 문제는 같은 방법끼리 단원마다 1~2개만 둔다.
  - 유형서에 꼭 필요한 방법이 기본서에 없으면 기본서에 대표 문제를 보충한다. (1단원 021 차수 따지기, 022 f(x)=t로 놓는 항등식)
- 이 책은 학원 기본서로 수업한 뒤 과제로 내는 유형서다.
- 기본서와 **숫자까지 똑같은 문제는 넣지 않는다.** 단원마다 기본서 문제를 모두 옮겨 적어 대조한다.
- 기본서의 어려운 문제 몇 개는 숫자·조건을 바꾼 변형 문제로 넣는다.
- 목차는 아래 12단원 기준이다(기본서 파일이 13개로 나뉘어 있어도 무시). 기본서는 해당 단원을 만들 때 다시 받아 대조한다.
- 올림포스 두 권은 별도의 정답과 풀이 PDF가 있다. 모든 문항은 정답과 풀이를 대조하고 계산으로 다시 검산한다.

## 문항 형식
- 단답형을 기본으로 한다. 단답형으로 바꾸면 어색한 문제(보기 ㄱㄴㄷ, 식 자체가 답 등)는 5지선다를 유지한다.
- 단답형의 답은 숫자 하나로만 나오게 한다.
  - "a, b의 값을 각각 구하시오" → "a+b의 값을 구하시오"
  - "k의 값의 범위를 구하시오" → "정수 k의 개수를 구하시오"
- 수식 처리: **문제에 속한 수와 영문자만 수식으로** 쓴다. 기본서의 개념 설명 문단은 원본 그대로 두고 수식으로 바꾸지 않는다.

### 기본서 (학원 기본서 수정본, `기본서/`)
| 단원 | 파일 | 유형 | 문항 |
|---|---|---|---|
| 1. 다항식의 연산과 항등식 | `기본서/1. 다항식의 연산과 항등식.hwpx` | 7 | 42 (STEP 2 22 + STEP 3 20) |
| 2. 나머지정리 | `기본서/2. 나머지정리.hwpx` | 8 | 40 (STEP 2 22 + STEP 3 18) |

- 원본은 `기본서/원본/`. 1단원은 「1. 다항식의 연산」과 「2. 항등식」을 합쳤고, 2단원은 「3. 나머지정리」의 단원 번호를 2로 바꿨다.
- 문항 번호는 책 전체로 이어진다: 1단원 001~042, 2단원 043~082(번호가 없던 문항에도 번호를 넣음). 해설(미주) 번호도 같다. 2단원 시작 번호는 `compose2.py`의 `START`.
- 단답형으로 바꿀 수 있는 문항은 모두 바꿨다(선택지를 지우고 정답을 값으로, "~은?" → "~을 구하시오."). 1단원 36문항, 2단원 31문항. 바꾸는 코드는 `도구/기본서/shortans.py`.
- 5지선다로 남긴 문항: 003(답이 식), 024(삼각형 모양), 046(답이 다항식), 064·072(보기 ㄱㄴㄷ), 073(답이 n에 대한 식)
- 1단원 유형 07(다항식의 나눗셈과 항등식)에 대표 문제 2개를 보충했다(021, 022). 넣는 코드는 `도구/기본서/addprob.py`.
- 1단원 단원 마무리는 34문항에서 20문항으로 줄였다(쉬운 문항·겹치는 문항 14개 뺌).
- 검수에서 고친 것: 정답·해설 오류, 빠진 해설, 시험지 흔적([점], 서답형, 출처 줄), 정답 표기(󰂼 ③으로 통일), 조사 오타. 수정 목록은 `도구/기본서/fixA.py`(다항식의 연산), `fixB.py`(항등식), `fixC.py`(나머지정리).
- 유형서는 수정한 기본서와 숫자까지 같은 문제를 넣지 않는다.

- 3단원(인수분해)을 만들 때 쓸 문항: `unit02.py`의 2:13({f(x)}²=(x+3)(x+1)(x-2)(x-4)+k, 공통부분 묶기), `unit2_extra.json`의 c19(2026×2027×2028×2029-48의 나머지). 1·2단원에서는 뺐다.

- `공통수학1/미리보기/*.pdf`는 내용 확인용(수식·문장·정답)이다. 실제 쪽 배치는 한글에서 열어 확인한다.
- 모든 정답은 `도구/verify*.py`로 계산해 다시 확인했다(불일치 0).

## 다시 만들기 (문항을 고친 경우)
```
cd 도구
export KATEX_DIR=<katex 설치 위치>/node_modules/katex/dist                # 새 수식 크기 측정·미리보기에 필요
# 정답 검산
python cmpans.py unit1n.py 1=verify01.py 2=verify02.py
python cmpans.py unit2n.py 1=verify01.py 2=verify02.py 3=verify2n.py
# 유형서 만들기
python gen.py ../기본폼_공통수학1_01.hwpx ../서식샘플.hwpx unit1n.py ../공통수학1/01_다항식의_연산과_항등식.hwpx
python gen.py ../기본폼_공통수학1_01.hwpx ../서식샘플.hwpx unit2n.py ../공통수학1/02_나머지정리.hwpx
python validate.py ../공통수학1/02_나머지정리.hwpx ../기본폼_공통수학1_01.hwpx
python preview_hwpx.py ../공통수학1/02_나머지정리.hwpx ../공통수학1/미리보기/02_나머지정리_내용확인.pdf
# 기본서 만들기
cd 기본서
python compose1.py "../../기본서/원본/1. 다항식의 연산.hwpx" "../../기본서/원본/2. 항등식.hwpx" "../../기본서/1. 다항식의 연산과 항등식.hwpx"
python compose2.py "../../기본서/원본/3. 나머지정리.hwpx" "../../기본서/2. 나머지정리.hwpx"
```
- 유형서 단원 파일: `unit1n.py`, `unit2n.py`. 문항 자체는 `unit01.py`(1:), `unit02.py`(2:), `unit2_extra.json`(3:, 2단원 보충)에 있고, 단원 파일은 이를 골라 순서를 정한다. `v`(예: `2:44`)로 검산 파일과 짝을 맞춘다.
- `LEVEL`에 상·최상, `OLYMPOS`에 올림포스 고난도 문항을 적어 둔다.
- 문항 표현: `{"box": [...]}` 조건 상자, `{"bogi": [...]}` 보기 상자, `{"syn": [[...]]}` 조립제법 표, `{"pic": "imageNN"}` 폼 안의 그림, `{"ch": [...]}` 5지선다 선택지
- 수식 크기는 `eqcache.json`에 저장돼 있고, 새 수식이 생기면 KaTeX로 잰다(`npm install katex` 후 `KATEX_DIR` 지정, playwright 필요).
