# 공통수학 유형 문제집 제작 기준

학원 내부 수업용. 공통수학1 → 공통수학2 순서로 2권 제작.

## 파일 형식
- HWPX, 단원별 1파일 (`01_다항식의_연산.hwpx` … `12_행렬.hwpx`)
- 틀은 `기본폼_공통수학1_01.hwpx`(학원 한글 폼)를 그대로 쓴다: 2단, 한 단에 한 문제, 유형 제목 상자, 단원 머리표, 머리말·쪽 번호, 끝의 「정답 및 풀이」
- 보기 박스, 조건 박스, 두 줄 식(구간별 식), (가) 꼬리표는 `서식샘플.hwpx` 형식을 따른다.
- 해설은 미주(문제 끝에 정답·해설)로 넣는다. 미주 번호가 곧 문제 번호다.
- 모의고사 문항은 번호 옆에 출처를 적는다. (예: 2025년 6월 고1 14번 [4점])

## 구성 (2스텝)
- **STEP 1**: 참고 교재(일품)의 1스텝(개념 & 핵심 기출)과 2스텝(고난도)을 같은 개념끼리 합친 유형별 문제
- **STEP 2**: 고난도 문제 (폼의 「고난도」 제목, 새 쪽에서 시작)
- 유형 제목은 일품의 개념 이름을 쓴다.
- 비율: STEP 1 약 75% / STEP 2 약 25% (1단원 기준 45 + 15)
- 너무 단순한 쉬운 문제는 유형마다 1개까지만

## 분량
- 1단원: 약 60문항
- 2~12단원: 단원마다 70~90문항

## 문제 출처
| 출처 | 사용 기준 | 출처 표기 |
|---|---|---|
| 내신 기출 | 기본 | 안 함 |
| 모의고사(학력평가) | 4점 문항만 | 함 (예: 2025년 9월 고1 학력평가 17번) |
| 올림포스 고난도 (EBS) | 단원마다 20% | 안 함 |
| 올림포스 유형편 (EBS) | 내신·모의고사로 부족한 유형만 채움 | 안 함 |

- 단원 구성 참고 교재: 일품 공통수학1 591제 (좋은책신사고). 문제는 가져오지 않고 개념 순서만 참고한다.
- 올림포스 두 권은 별도의 정답과 풀이 PDF가 있다. 모든 문항은 정답과 풀이를 대조하고 계산으로 다시 검산한다.

## 문항 형식
- 단답형을 기본으로 한다. 단답형으로 바꾸면 어색한 문제(보기 ㄱㄴㄷ, 식 자체가 답 등)는 5지선다를 유지한다.
- 단답형의 답은 숫자 하나로만 나오게 한다.
  - "a, b의 값을 각각 구하시오" → "a+b의 값을 구하시오"
  - "k의 값의 범위를 구하시오" → "정수 k의 개수를 구하시오"

## 다시 만들기 (문항을 고친 경우)
```
cd 도구
python verify02.py && python cmpans.py unit02.py verify02.py            # 정답 검산
python gen.py ../기본폼_공통수학1_01.hwpx ../서식샘플.hwpx unit02.py ../공통수학1/02_항등식과_나머지정리.hwpx
python validate.py ../공통수학1/02_항등식과_나머지정리.hwpx ../기본폼_공통수학1_01.hwpx
python preview_hwpx.py ../공통수학1/02_항등식과_나머지정리.hwpx ../공통수학1/미리보기/02_항등식과_나머지정리_내용확인.pdf
```
- 문항 내용은 `unit01.py`, `unit02.py`(문제 `q`, 정답 `ans`, 해설 `sol`, 모의고사 출처 `src`)
- 수식 크기는 `eqcache.json`에 저장돼 있고, 새 수식이 생기면 KaTeX로 잰다(`npm install katex` 후 `KATEX_DIR` 지정, playwright 필요).
- 표현: `{"box": [...]}` 조건 상자, `{"bogi": [...]}` 보기 상자, `{"syn": [[...]]}` 조립제법 표, `{"pic": "imageNN"}` 폼 안의 그림, `{"ch": [...]}` 5지선다 선택지
