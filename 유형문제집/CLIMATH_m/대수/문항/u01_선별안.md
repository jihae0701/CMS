# CLIMATH(m) 대수 1단원 '지수' — 문항 선별안 (2026-11-24, 확인 대기)

분류는 CLIMATH(c) 대수 1. 지수 그대로(STEP1 개념 01~03, STEP2 유형 01~04).
- 고난도 = 올림포스 고난도 대수 01(번호), 해설 있음 → 해설 그대로.
- 유형ON = 유형 문제집 대수 1권(번호 0001~), 빠른 정답만 → 풀이는 새로 써서 정답과 맞춤.
- ★ = 대표문제·중요 표시, 서 = 서술형, 기 = 교육청·평가원 기출.
