# 예비고1 반편성고사 (공통수학1·2)

## 파일
| 파일 | 용도 |
|---|---|
| `시험지/예비고1_반편성고사_공통수학1.hml` | 공통수학1 시험지(한글). 문제 → 빠른 정답 → 해설(미주) 순서 |
| `시험지/예비고1_반편성고사_공통수학2.hml` | 공통수학2 시험지(한글) |
| `시험지/미리보기_공통수학*.pdf` | 내용 확인용 미리보기(실제 인쇄본은 HML) |
| `예비고1_반편성고사_채점_반배정.xlsx` | 채점 · 반 배정 · 문항 분석. 정답/배점/단원/난이도가 시험지와 맞춰져 있음 |
| `도구/` | 문항 데이터(`problems.py`)와 생성·검증 스크립트 |

## 시험 구성 (과목별 동일)
- 20문항 60분, 1~14번 객관식 · 15~20번 단답형, 100점
- 난도별 배점: 하 3점 · 중하 4점 · 중 5점 · 중상 6점 · 상 7점 · 최상 8점
  (객관식 최고 7점: 14번은 최상 난도지만 7점, 단답형 20번만 8점)
- 2022 개정 교육과정에서 빠진 외분점은 쓰지 않음
- 2025·2026년 3월 고2 학력평가 문항을 숫자·조건을 바꿔 변형, 정답은 `도구/verify_all.py`로 전수 검증

## 진행 순서
1. HML 시험지를 한글에서 열어 인쇄
2. 엑셀 `학생명단`에 학생 정보 입력, `공수1`·`공수2`에 학생이 쓴 답을 그대로 입력
3. `반배정` 시트에서 자동 배정 확인 (절대평가, 기준은 `설정` ①에서 수정 가능)
   - TF1반: 공통수학1 60점 이상 · 공통수학2 60점 이상
   - TF2반: 공통수학1 60점 이상 · 공통수학2 40점 미만
   - TF3반: 공통수학1 40점 미만 · 공통수학2 40점 미만
   - 그 외(또는 미응시 과목 있음): 보류 → 상담 후 `수동조정` 칸에서 반 지정
4. `설정` 시트에서 학원명·시험일·평균 표시 여부·학습 제언 문구 확인
5. 학부모 보고서·상담 카드 생성
   ```
   python 도구/make_reports.py 예비고1_반편성고사_채점_반배정.xlsx 결과
   ```
   - `결과/학부모보고서_한글/번호_이름.hml`, `결과/학부모보고서_한글/전체.hml` : **수정 가능한 한글 파일**.
     석차·백분위 없이 성취 수준, 전체 평균(설정에서 숨김 가능), 종합 의견, 추천 반(빈칸 — 직접 작성)
   - `결과/학부모보고서_전체.pdf`, `결과/학부모보고서/번호_이름.pdf` : 같은 내용의 PDF
   - `결과/상담카드_전체.pdf` : 내부용. 자동배정(보류 여부), 기준 점수와의 차이, 경계 여부, 문항별 정오(○/×), 틀린 문항의 평가 요소·정답률
