# 예비고1 진단평가 (공통수학1·2, 반 배정용)

## 파일
| 파일 | 용도 |
|---|---|
| `시험지/예비고1_진단평가_공통수학1.hwpx` | 공통수학1 시험지(한글 hwpx). 학원에서 손본 편집(표지·머리말·CLIMATH 로고·5지선다형/단답형 표시·조건 상자)을 그대로 사용, 문제 → 빠른 정답 → 해설(미주) 순서 |
| `시험지/예비고1_진단평가_공통수학2.hwpx` | 공통수학2 시험지(같은 형식) |
| `시험지/미리보기_공통수학*.pdf` | 문항·해설 내용 확인용 미리보기(인쇄본은 hwpx) |
| `예비고1_반편성고사_채점_반배정.xlsx` | 채점 · 반 배정 · 문항 분석. 정답/배점/단원/난이도가 시험지와 맞춰져 있음 |
| `도구/` | 문항 데이터(`problems.py`)와 생성·검증 스크립트 |

## 시험 구성 (과목별 동일)
- 20문항 60분, 1~14번 객관식 · 15~20번 단답형, 100점
- 1~6번: 하·중하(3·4점), 7번부터 난도 상향
  - 7~9번·15~17번: 중상 5점 / 10~12번·18번: 상 6점 / 13·14번·19번: 최상 6점 / 20번: 최상 7점
  - 6점은 모두 상 이상 난도, 7점은 가장 어려운 20번 한 문항
- 2022 개정 교육과정에서 빠진 외분점은 쓰지 않음
- 참고 모의고사(숫자·조건을 바꿔 변형): 2024·2025·2026년 3월 고2, 2025년 10월 고1, 2026년 9월 고1
- 정답은 `도구/verify_all.py`로 40문항 전수 검증(직접 세기·연립방정식 풀이 등 별도 계산)

## 진행 순서
1. hwpx 시험지를 한글에서 열어 인쇄 (단 나눔·풀이 여백은 필요하면 한글에서 조정)
2. 엑셀 `학생명단`에 학생 정보(기존 반명 — 신규 학생은 '신규', 학습 진도 포함) 입력
   - 객관식 1~14번: 학생이 답안지에 표시 → 스캔해서 올리면 판독해 `공수1`·`공수2`에 자동 입력(아래 '답안지 스캔 판독')
   - 단답형 15~20번: 맞으면 **1**, 틀리면 **0** (각 열 머리에 정답 표시). 스캔 판독 때 손글씨 답을 읽어 함께 채점 가능
3. `반배정` 시트에서 자동 배정 확인 (절대평가, 기준은 `설정` ①에서 수정 가능)
   - TF1반: 공통수학1 60점 이상 · 공통수학2 60점 이상
   - TF2반: 공통수학1 60점 이상 · 공통수학2 40점 미만
   - TF3반: 공통수학1 40점 미만 · 공통수학2 40점 미만
   - 그 외(또는 미응시 과목 있음): 보류 → 상담 후 `공통수학반(입력)` 칸에서 반 지정
   - 학생마다 **2개 반 수강**: 공통수학반 1개(시험 결과 기준, 입력하면 자동배정보다 우선) + 선행 과목반 1개(`선행반(입력)`, 학습 진도 보고 선택)
   - 반 소개 문구: 공통수학반은 `설정` ⑥, 선행 과목반은 `설정` ⑦(비어 있음 — 반 이름·소개가 정해지면 입력)
   - 아직 정하지 않은 반은 보고서에 '개별 상담을 통해 안내해 드립니다'로 표시되고, 입력 후 다시 생성하면 채워짐
4. `설정` 시트에서 학원명·시험일·평균 표시 여부·학습 제언·반 소개 문구 확인
5. 학부모 보고서·상담 카드 생성
   ```
   python 도구/make_reports.py 예비고1_반편성고사_채점_반배정.xlsx 결과
   ```
   - `결과/학부모보고서_전체.pdf`(인쇄용), `결과/학부모보고서/번호_이름.pdf`(학생별) : CMS CLIMATH 학습유형 보고서와 같은 디자인, 학생당 2쪽
     (1쪽: 진단 요약·과목별 결과·단원별 성취도 / 2쪽: 문항별 결과·강점과 보완점·종합 의견·수강 추천 반(공통수학반 + 선행 과목반, 추천 근거 포함)·상담 안내)
     머리말에 CLIMATH 로고, 석차·백분위 없음, 전체 평균은 설정에서 숨김 가능. 보고서 내용은 모두 엑셀에서 수정 후 다시 생성
   - `결과/상담카드_전체.pdf` : 내부용. 기존 반·학습 진도, 자동배정(보류 여부)·공통수학반·선행반, 기준 점수와의 차이, 경계 여부, 문항별 정오(○/×), 틀린 문항의 평가 요소·정답률

## 시험지 다시 만들기 (문항을 고친 경우)
```
python 도구/verify_all.py                      # 정답 검증
python 도구/make_hwpx.py 도구/assets/exam_template.hwpx 도구/figs 시험지   # hwpx 시험지
python 도구/preview.py 시험지 도구/figs          # 미리보기 PDF
python 도구/build_workbook.py 예비고1_반편성고사_채점_반배정.xlsx   # 엑셀(정답·배점) — 입력한 학생 자료가 지워지므로 빈 파일일 때만
```
- 문항 내용은 `도구/problems.py`, 틀은 학원 편집본(`도구/assets/exam_template.hwpx`)
- 수식 크기 계산에 KaTeX가 필요: `npm install katex` 후 `KATEX_DIR=.../node_modules/katex/dist`

## 답안지 스캔 판독 (객관식 1~14번)
- 답안지(학교·이름 + ①~⑤ 표)를 학생이 표시한 뒤 스캔(PDF 여러 쪽 또는 JPG/PNG, 200dpi 이상 권장)
- 가로·세로 어느 방향으로 스캔해도 되고(자동 회전), 표 테두리를 찾아 기울기를 바로잡고, ①~⑤ 칸마다 인쇄된 글자보다 더 진한 잉크를 비교해 표시한 번호를 읽음
  (까맣게 칠하기·동그라미·체크·사선·X 모두 판독. 표시 없음/두 개 이상/흐린 표시는 '확인 필요')
```
python 도구/omr_read.py 판독_공수1 스캔_공수1.pdf        # 판독결과.json + 확인_XX.png(이름 칸·판독값)
python 도구/omr_fill.py 예비고1_반편성고사_채점_반배정.xlsx 공수1 판독_공수1/판독결과.json 짝맞춤.csv [수정.csv]
```
- `짝맞춤.csv`: `쪽,학생`(학생명단 No 또는 이름 — 답안지의 이름·학교·현재반을 보고 매칭)
- `수정.csv`: `쪽,문항,답[,읽은 답]` — 확인 그림을 보고 고친 객관식 답, 단답형 15~20번 채점 결과(1/0)와 학생이 쓴 답
- 확인 그림에는 단답형 답 칸이 파란 번호로 표시됨. 엑셀 `판독기록` 시트에 확인했던 객관식 줄과 단답형 채점 내역이 남음
- 표시 없음은 빈칸, 두 개 이상 표시는 0(오답)으로 입력. 입력 전 원본은 `_백업.xlsx`로 남김
- 필요: `pip install opencv-python-headless`, poppler(pdftoppm)
