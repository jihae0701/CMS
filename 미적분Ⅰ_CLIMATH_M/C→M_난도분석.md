# 미적분Ⅰ CLIMATH ⓒ → ⓜ 난도 분석

같은 단원 구성(10단원, STEP 1 개념 / STEP 2 유형 / STEP 3 단원 마무리)의 C 원본과 M 원본을 문항별로 맞대어 보았다.
목적: 앞으로 주어진 CLIMATH ⓒ(예: 대수)에서 CLIMATH ⓜ를 만들 때 쓸 기준을 남긴다.

- 비교 방법: 문제 글·수식을 이어 붙인 뒤 비슷한 정도(0~1)로 짝을 지음 (도구: `도구/compare.py`, 결과: `비교/uNN.json`)
  - 다시 검토(개념·유형 상자 글자, 수식 쓰는 방식 차이를 빼고 M 문항마다 가장 가까운 C 문항과 비교, 짝마다 눈으로 확인):
    **똑같음** = 문장·수식·숫자·선지가 C와 같음, **비슷함** = C 문항과 같은 유형·같은 틀에서 함수·숫자·묻는 것을 바꿈, **새 문제** = C에 짝이 될 문항이 없음
- 문항 수·STEP·객관식 수는 **원본 기준**(사용자 지시에 따른 단답형 바꾸기 전)

## 1. 한눈에

| | C | M | 차이 |
|---|---|---|---|
| 전체 문항 | 479 | 577 | +98 (+20%) |
| STEP 1 | 200 | 253 | +53 |
| STEP 2 | 173 | 188 | +15 |
| STEP 3 | 106 | 136 | +30 (+28%) |
| 객관식(원본) | 243 | 310 | +67 |
| 해설 길이(평균, 글자) | 436 | 529 | +21% |

M 577문항의 출처:

| 똑같음 | 비슷함 | 새 문제 |
|---|---|---|
| 약 390 (67%) | 약 70 (12%) | 약 115 (20%) |

똑같이 남은 문항은 C의 오류까지 그대로 가지고 있다(예: C 2단원 43번의 정답 오류가 M 2단원 51번에 그대로, C 7단원 31·32번이 같은 문제인 것이 M 7단원 15·35번에도 그대로).
비슷한 문제의 예: C 9단원 34번 g(x)=∫ₓ^{x+2}f(t)dt의 최소 → M 26번 g(x)=∫ₓ^{x+1}f(t)dt의 최소, C 10단원 41번 y=x³과 y=k 사이 두 넓이가 같을 때 → M 48번 y=x²과 y=k 사이 두 넓이의 합이 최소일 때, C 2단원 28번 f(x)g(x)의 연속 → M 17·18번 f(x){f(x)+k}, f(x)f(x−a)의 연속

C 479문항 중 약 390문항(81%)이 M에 똑같이 남았고, 나머지 약 90문항은 비슷한 문제로 바뀌었거나 빠졌다(주로 STEP 2의 쉬운 연습형, 같은 유형 반복).

**요약: M = C 문항 약 2/3를 똑같이 + C 유형을 바꾼 비슷한 문제 약 1/8 + C에 없는 새 문제 약 1/5.** C와 다른 문항(비슷함·새)은 STEP 3에 가장 많이 몰리고, 해설이 길어진다(문항당 +21%). 같은 문항 수 안에서 쉬운 반복 문항을 덜어 내고, 조건이 여러 겹인 문항을 넣는 방식이다.

## 2-1. 같은 STEP끼리 비교 (STEP 1↔1, 2↔2, 3↔3)

같은 STEP끼리 견주어도 M이 모든 STEP에서 더 어렵다. 다만 올린 정도가 STEP마다 다르다: STEP 1은 조금, STEP 2는 중간, STEP 3은 크게.

| 지표 | STEP 1 C → M | STEP 2 C → M | STEP 3 C → M |
|---|---|---|---|
| 문항 수 | 200 → 253 | 173 → 188 | 106 → 136 |
| 해설 길이(문항당) | 491 → 525 (+7%) | 380 → 446 (+17%) | 425 → 653 (**+54%**) |
| 문제 길이(문항당) | 143 → 159 (+11%) | 133 → 145 (+9%) | 191 → 180 (−5%) |
| (가)(나) 조건 | 1.5% → 6.7% | 3.5% → 4.3% | 4.7% → **17.6%** |
| 개수·최댓값을 함수 g(t)로 | 1.0% → 2.4% | 0% → 2.7% | 0% → **8.8%** |
| 절댓값 | 6.0% → 7.1% | 5.8% → 9.6% | 5.7% → **14.0%** |
| 최대·최소 | 8.0% → 9.5% | 9.8% → 10.1% | 9.4% → 12.5% |
| “모든 ~의 합” | 1.0% → 2.0% | 1.2% → 2.7% | 0% → 3.7% |
| M 중 C와 똑같은 문항 | 75% | 71% | **46%** |

- **STEP 1**: 3/4이 C와 같다. 대신 C STEP 2의 쉬운 유형 문제가 내려오고 (가)(나) 조건 문제가 조금 들어와(1.5% → 6.7%) 문제 길이가 11% 늘었다. 개념 확인 단계도 한 단계 무거워진 정도.
- **STEP 2**: 7할이 C와 같고, 바뀐 문항은 절댓값·구간별 함수·g(t)처럼 꼴을 복잡하게 만든 것. 해설 +17%.
- **STEP 3**: 절반 이상이 C와 다른 문항이고 해설이 1.5배. (가)(나) 조건이 4배, g(t) 문제가 0에서 9%로. 문제 길이는 오히려 짧아(−5%) 짧은 문제에 풀이가 긴, 압축된 고난도 문항으로 바뀌었다.

## 3. M이 난도를 올리는 방법 (새 문항·바꾼 문항의 유형)

### ① 함수의 꼴을 복잡하게
- **가우스 기호** `[x]`가 든 극한·연속(1단원 15~19번: `[x]²+a[x]`의 극한이 존재할 조건, `[x²]`의 좌·우극한)
- **절댓값**이 든 함수의 극한·연속·미분가능성: `|x-2|/(x-2)`, `x²-4|x|+3`, `(x-t)|x(x-3)|`, `|f(x)-k|`
- **구간별로 정의된 함수에 미지수**: `f(x)f(x-2)`의 연속(2단원 51), `f(x)g(x)`의 미분가능(3단원 47), 미지수 a를 구간 끝으로 둔 함수(2단원 47)
- **주기함수·함수방정식**: `f(x+2)=f(x)`, `f(2x-1)=2f(x)-3`(2단원 52), `f(x+y)=f(x)+f(y)+xyf(x+y)`(3단원 23), `f(x)+f(k-x)=k`(8단원 55)
- **합성·역함수**: `(f∘f)(x)`의 불연속점(2단원 40), `(f∘g)`의 최댓값(5단원 18), 역함수가 있을 조건(5단원 27·51), `f'∘g` 방정식(6단원 51), 역함수의 넓이(10단원 36)

### ② 조건을 여러 겹으로
- **(가)(나)(다) 조건**으로 함수를 정하게 함: 대칭 + 극값 + 값, 극한 조건 + 연속 조건, 정적분 조건 두 개(8단원 26·57)
- **매개변수에 따라 달라지는 개수를 함수로**: `g(t)`= 미분가능하지 않은 점의 개수(3단원 61), `f(a)`= 교점·근의 개수(2단원 41·56), `h(t)`= 두 거리 중 작지 않은 값(3단원 62), `g(t)`= 구간 `[t, t+1]`에서의 최댓값(8단원 59)
- **최대·최소를 한 번 더**: 넓이의 최솟값을 주는 t(10단원 12·48), `∫f`의 최댓값−최솟값(9단원 12), 정수 k의 개수·합

### ③ 보기 ㄱ·ㄴ·ㄷ로 개념의 참·거짓
- 극한·연속·미분가능성의 성질(1단원 22·53·55, 2단원 16·45·52, 3단원 31·46·48·60·61, 6단원 50, 9단원 43, 10단원 52)
- 반례를 직접 만들어야 하는 보기가 들어감(3단원 60 ㄴ, 5단원·9단원)

### ④ 도형·좌표와 엮은 극한
- 접선·법선·수직이등분선이 축과 만나는 점의 극한(1단원 60~62), 내접원·외접원(1단원 63), 움직이는 점이 만드는 넓이의 극한(1단원 78)

### ⑤ 다른 과목·단원과 엮기
- **수열의 합 Σ**: `Σ f(n)`(1단원 33), `Σ ∫₀ᵏ 2f`(8단원 55), 부분분수(2단원 56)
- **나머지정리**: `(x-1)²`으로 나눈 나머지와 미분(3단원 59)
- **이차부등식의 정수해 개수**를 함수로(2단원 56), 판별식으로 역함수 조건(5단원 51)
- **평균값 정리**로 범위 구하기(4단원 19·20·55)

### ⑥ 실제 상황(속도·변화율) 문제를 늘림
- 6단원: 레일 위 열차의 높이 변화율, 넓이·부피의 시간 변화율, 원 위를 도는 두 점의 만남 횟수(6단원 20~22·35·36·46·47)

### ⑦ 묻는 방식
- 객관식을 단답형으로 바꾼 문항이 있다(원본에서도). 거꾸로 C의 단답형을 M이 객관식으로 둔 곳은 거의 없다.
- 서술형(채점 기준 표 포함, 3단원 57, 9단원 25)이 STEP 3에 들어감.

## 4. ⓒ에서 ⓜ를 만들 때의 기준 (대수 ⓜ 제작에 적용)

> 사용자 결정: **대수 ⓜ는 C 문항의 30% 이하만 그대로 쓰고, 나머지는 숫자와 조건을 바꿔 쓴다.**
> (미적분Ⅰ ⓜ 원본은 C 문항의 약 2/3를 그대로 썼지만, 대수부터는 이 기준을 따른다.)
> 같은 STEP끼리도 M이 더 어렵게: STEP 1은 조금(조건 하나 더), STEP 2는 중간(꼴을 복잡하게), STEP 3은 크게(조건 여러 겹·g(t)·해설 1.5배) 올린다(2-1장).

1. **그대로 쓰는 문항은 C 문항의 30% 이하.** 개념 확인용 STEP 1 기본 문제 위주로 남긴다. 같은 유형 반복(숫자만 다른 연습 2~3개)은 하나만 남긴다.
2. **나머지 C 문항(70% 이상)은 숫자와 조건을 바꿔 쓴다.** 같은 유형·같은 풀이 틀을 지키되:
   - 숫자 바꾸기: 계수·구간·주어진 값을 바꾸고 답이 깔끔하게 나오는지 직접 풀어 확인
   - 조건 바꾸기: 묻는 것을 한 단계 뒤로(극솟값 → 극댓값, 값 → 모든 값의 합, 하나 → 모든 k), 조건 하나를 더하거나 순서를 바꿈(“~일 때 ~를 구하시오” ↔ “~가 되도록 하는 ~”)
   - 보기 ㄱ·ㄴ·ㄷ 문제는 참·거짓이 바뀌도록 보기 하나 이상을 바꿈
   - 바꾼 문항은 정답·해설을 새 숫자·조건에 맞게 모두 다시 씀(그림도 새 값으로 다시 그림)
3. **문항 수를 약 20% 늘린다.** 단원당 +6~+20문항. 늘린 만큼의 약 40%는 STEP 3에, 나머지는 STEP 1·2에 고르게. C STEP 2의 쉬운 문항 일부는 M STEP 1로 내린다.
4. **늘리는 문항(새 문항)을 만드는 틀** (3장의 ①~⑥에서 고름):
   - 같은 개념을 **절댓값·가우스 기호·구간별 함수·미지수**가 든 꼴로
   - **(가)(나)(다) 조건**으로 대상을 정하게
   - **매개변수 t에 따른 개수·최댓값을 함수 g(t)로** 두고 그 함수의 성질을 묻게
   - **ㄱ·ㄴ·ㄷ 참·거짓**(한 보기는 반례가 필요하게)
   - **도형·좌표**와 엮거나 **다른 단원(수열, 나머지정리, 부등식)**과 엮기
5. **해설**은 경우 나누기·표·그림을 넣어 길어진다(평균 +20%). 바꾼 문항·새 문항에는 반드시 해설을 쓰고, 다른 풀이를 붙이는 것도 M의 특징이다.
6. **검산**: 미적분Ⅰ ⓜ 원본의 오류는 새로 넣거나 바꾼 문항에 몰려 있었다(정답 오류 6, 문제·해설 어긋남 5). 바꾼 문항은 모두 직접 풀어 정답·선지·해설을 맞춘다.
