# 미적분Ⅰ CLIMATH(M) 수정기록

원본: 사용자가 올린 M 10단원(`원본/`). C를 고칠 때와 같은 약속으로 고쳤다.

## 공통

- 틀: C 1단원 기준 파일의 틀(STEP 제목, 쪽 번호 1부터, 굵은 글씨 정리)에 옮겨 담음. **바탕쪽의 ⓒ → ⓜ (“CLIMATH ⓜ”)**
- 수식 자동 정리(C와 같은 도구): lim 아래 첨자 `lim _{x `->` a}`, 분수·괄호·띄어쓰기, 음수 `it-`, 점 이름 `rm`, 빈 묶음, 수식 뒤 빈칸, 줄 배치 정보
- 정답 머리를 “[정답]”(굵지 않게)으로 통일(정답/답./답/[[정답]]/정답 그림 등), 끝의 정답 모음 지움, “구하여라” → “구하시오” 등 낱말 통일
- **C에서 고친 것 옮기기**: C와 같은 문항(문제·해설 수식이 같은 것)을 찾아 C의 고침 명령을 M 번호로 바꿔 적용(577문항 중 337문항)
- 나머지(새 문항·바뀐 문항)는 한 문항씩 풀어 보며 검토: 보기 ㄱㄴㄷ·“옳은/옳지 않은 것”·식이나 구간을 고르는 문제는 객관식 유지, 그 밖에는 단답형으로 바꾸고 정답 줄을 값으로
- “[해설]·[풀이전략]·[문제풀이]·[step]” 같은 머리줄 지움
- 수식 속 출처 꼬리표(`{from^2021^09^평가원^중}` 등) 지움, 수식 속 단위·한글(“/초”, “(단, …)”, “(a는 0이 아닌 상수)”)은 수식 밖 글로
- 묶지 않은 음수·식 첨자 바로잡음: `int_-1^1` → `int_{-1}^1`, `x^-2` → `x^{-2}`, `sum_k=1^10` → `sum_{k=1}^{10}` (한글 수식의 첨자는 다음 낱말 하나만 받으므로). C 8~10단원에도 같은 꼴이 있어 함께 고침
- 표 개체의 숨은 설명(문서에 보이지 않음)에 남아 있던 사람 이름 → “표입니다.” (4·6·7·9·10단원)
- 그림: C와 같은 그림은 C에서 다시 그린 그림을 그대로 넣고, C에 없던 스캔 그림은 새로 그림(긴 변 10000 HWPUNIT, 두 칸 그림 18000, 진한 칠은 연한 색). 보기·참고·다른풀이 표시 그림은 그대로
- 검사: 단원마다 그림 검사, 일관성 검사, 수식 검사, XML, hwpxlib OK (7·8단원 그림 검사의 “해설 그림 1→0”은 그림으로 되어 있던 정답 머리를 글 “[정답]”으로 바꾼 것)
- 도구·명령: `도구/`(port_cm.py, mjedit.py, hwpxedit.py, negsub.py 등), 단원별 고침 명령 `작업중/mM_NN_edit*.py`, 그림 `그림/mM_NN/draw.py`
